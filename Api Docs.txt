Perfect, Tony. Now I have your actual project structure, so let's integrate Swagger step by step.

Step 1: Install Swagger Packages

Open terminal in your project folder:

npm install swagger-ui-express swagger-jsdoc


---

Step 2: Create swagger.js

Create a new file in the root folder:

project/
│
├── crudapi.js
├── crudserver.js
├── swagger.js   ← New
└── ...

Add:

const swaggerJsDoc = require("swagger-jsdoc");

const options = {
  definition: {
    openapi: "3.0.0",
    info: {
      title: "CRUD API",
      version: "1.0.0",
      description: "Simple CRUD API using Express and MySQL"
    },
    servers: [
      {
        url: "http://localhost:3000"
      }
    ]
  },
  apis: ["./crudapi.js"]
};

module.exports = swaggerJsDoc(options);


---

Step 3: Modify crudserver.js

Add these two imports near the top:

const swaggerUi = require("swagger-ui-express");
const swaggerSpec = require("./swagger");

So the top becomes:

const express = require("express");
const path = require("path");
const dotenv = require("dotenv");
const swaggerUi = require("swagger-ui-express");
const swaggerSpec = require("./swagger");

const apiRoutes = require("./crudapi.js");


---

Step 4: Add Swagger Route

Place this before app.listen():

app.use(
  "/api-docs",
  swaggerUi.serve,
  swaggerUi.setup(swaggerSpec)
);

Your file will look like:

app.use("/crudapi", apiRoutes);

app.use(
  "/api-docs",
  swaggerUi.serve,
  swaggerUi.setup(swaggerSpec)
);

const PORT = process.env.PORT || 3000;

app.listen(PORT, () => {
  console.log(`Server running at http://localhost:${PORT}`);
});


---

Step 5: Document Your Routes

Since you mounted:

app.use("/crudapi", apiRoutes);

all endpoints actually become:

POST   /crudapi/posting
GET    /crudapi/viewing
PUT    /crudapi/updating/{id}
DELETE /crudapi/deleting/{id}
GET    /crudapi/testdb

Notice the /crudapi prefix.


---

Step 6: Add Swagger Comment Above POST Route

In crudapi.js, place this immediately above:

router.post("/posting", async (req, res) => {

One important note: your repository screenshot shows a .env file committed to GitHub. In real projects, .env should not be pushed to GitHub. Add it to .gitignore before making the repository public.
